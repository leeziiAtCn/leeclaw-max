
## XHS Scraper Bug - 评论 DOM 选择器失效

**发现时间：** 2026-04-14
**问题：** `xhs-batch-scraper.js` 的评论抓取 DOM 选择器 `.parent-comment` / `.comment-item` / `.user-name` 等均未匹配到元素，导致所有评论 content 和 nickname 为空。

**临时解决：** 旧文件 `xhs-kangnotes-scraped.jsonl`（昨天抓取）里有正确评论数据，且 note_id 相同。已将旧文件评论数据合并注入 `xhs-16621000470-scraped.jsonl`。

**根因：** 小红书网页 DOM 结构可能已变，旧选择器失效。需要重新抓包验证正确的评论 DOM 选择器。

**修复方向：**
- 评论 API：`edith.xiaohongshu.com/api/sns/web/v2/comment/page` 可直接拿到结构化评论数据（见 `xhs-note-scraper.js` 的 `fetchComments` 函数）
- 建议 batch-scraper 也调用同样 API 而非 DOM 提取
