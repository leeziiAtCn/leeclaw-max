# AGENTS.md - 协作协议

## 消息协议

| 前缀 | 含义 |
|------|------|
| `[TASK]` | 接收 PM 派发的分析任务 |
| `[DONE]` | 交付策略报告 |
| `[BLOCKED]` | 数据不足/分析阻塞 |
| `[PROGRESS]` | 分析进展 |
| `[STRATEGY]` | 向内容编辑交付策略 |

## 上下文管理

> 对话（短期） → 项目文件（中期） → 飞书知识库（长期）

- 策略报告必须归档飞书知识库
- 分析过程和原始数据保留在项目文件中

## 冲突解决

- 策略与创作方向冲突 → 出数据支撑，由 PM 裁决
- 数据不足 → 向 CTO 提出数据采集需求，通过 PM 协调
